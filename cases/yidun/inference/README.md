## 四、形态与难点

- **8 块、28 种交换**：答案空间是「交换哪一对」，不是逐块重排；只要找到正确的一对即可。
- **暗色遮罩**：易盾会在图上叠加平滑暗色遮罩或明暗渐变，逐段的亮度 ratio 会失真。
- **接缝不唯一**：自然纹理、重复图案可能让多个交换都“看起来连续”，需要全局成本而不是单条切缝。
- **块边界**：切块位置固定，但图像边缘可能被裁切；接缝两侧的纹理连续性要在原始像素上比较。
- **无逐组答案**：12 组只有 `solved.png`，没有 `answer.txt` / `result.json`，不能重算每组的 swap 数值。

## 五、求解思路

源方案先找「哪条切缝断得最明显」，再用两种信号投票：切缝断裂度/断裂段签名（结构）与全切缝成本（亮度不变）。

| 步骤 | 做法 | 关键判据 / 参数 |
|---|---|---|
| 1 切块 | 按固定网格切成 8 块 | 块尺寸与边界固定 |
| 2 断裂度 | 每条切缝两侧做差，统计断裂段 | 断裂越强越像原图接缝 |
| 3 签名 | 对断裂段做位置/长度签名 | 区分真实接缝与纹理干扰 |
| 4 全排列 | 枚举交换对，检查还原后的接缝一致性 | 28 种交换；双全排列/28 选 1 |
| 5 亮度不变成本 | 原始 + 高通 `I-GaussianBlur(σ=5)` 双通道，取全切缝平均跨缝差 | 暗色遮罩下只看轮廓/纹理 |
| 6 输出 | 取成本最低的交换对 | 08/09 已按该成本修正 |

```text
# 乱序拼图（伪代码，对应断裂度 + 全切缝成本）

blocks = split(bg, grid=8)
for pair in combinations(8, 2):              # 28 种交换
    img = swap(blocks, pair)
    cost_struct = seam_break_cost(img)       # 断裂度 + 断裂段签名
    cost_low    = seam_cost(img)             # 原始通道
    cost_high   = seam_cost(highpass(img))   # 高通 I-GaussianBlur(σ=5)
    cost_total  = w1*cost_struct + w2*(cost_low + cost_high)
    keep(pair, cost_total)

answer = argmin(cost_total)                  # 交换对
```

> 亮度不变的关键在高通通道：暗色遮罩/明暗渐变会改变绝对亮度，但轮廓与纹理的相对结构仍在；只看高通切缝成本，逐段 ratio 的偏差被压掉。

## 七、失败与边界

| 现象 | 根因 | 证据 | 结论 |
|---|---|---|---|
| 逐段 ratio 选出错误交换 | 暗色遮罩/明暗渐变改变局部亮度 | 08/09 旧答案错误，2026-11-20 修正 | 改用亮度不变的全切缝成本 |
| 多个交换都“看起来连续” | 自然纹理、重复图案 | 部分组出现多个低分候选 | 用全局成本 + 结构签名投票，不只看单条切缝 |
| 没有逐组 swap 数值 | 只保存 `solved.png` | 无 `answer.txt` / `result.json` | 只能人工目检还原效果 |
| 无法重算准确率 | 缺少逐组答案 | 12 组均为可视化结果 | 不要把检查图当成线上通过率 |
